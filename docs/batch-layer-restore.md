# Captured batch Restore Layer Source

Layer > Restore Layer Sources… and the Layers palette act on the captured
ordered retained-source vector. Confirmation names every layer. Cancel queues
nothing; Apply rechecks the same document, IDs and readiness after finishing
fields. A later front window or changed selection cannot redirect the command.
The service drains accepted input, counts exclusive work through result delivery,
reloads authoritative state on success or failure, and keeps close waiting.
Mask/channel targets, unresolved floating selections, busy/closing documents,
unknown IDs, unsupported sources and effective pixel/position locks refuse.

APIv1 appends slot166. The native service retains every attached target before
mutation, validates the whole vector and uses one native Undo group. Already
editable members are no-ops; a fully editable explicit vector adds no history.
Text sources work on all supported engines; native link/vector sources require
engines that implement them. Native regeneration can unexpectedly fail after a
changed prefix: the command reports failure honestly and leaves one Undo for
recovery. It does not promise atomic rollback or an immutable linked file.
