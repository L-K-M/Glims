# Upstream interface commits, GIMP 3.2.0 to 3.2.8: triage for Glims

Phase 0, week 3 (docs/plan.md). The 58 commits between `GIMP_3_2_0` and `GIMP_3_2_8` that touch GIMP's GTK-side files on the research focus list (`docs/research/scripts/focus_files.txt`): 48 interface-only and 10 that also touch the engine. GIMP's GTK code is not linked into Glims, so these are the changes that would not reach Glims by rebuilding against a new engine.

Classified on 2026-11-05 by two helper models from the diffs (Devin swe-2-max: first 29; GLM-5.3: last 29), each given the adapter sources and `docs/design.md`. Spot-checked by hand: `d125895a18` (only the existing-filter branch of `gimp_filter_tool_commit` changes; the adapter does not edit existing filters yet, so nothing to change now), `8af15d525a` (hash typo in the helper output corrected), `a950e63039` and `67084b7176` (consistent with the round 2 research reviews).

| Class | Count | Meaning |
|---|---|---|
| adapter | 1 | changes behavior `Engine/` reproduces; check or change the adapter |
| port | 28 | a behavior fix Glims's native equivalent should copy once it exists |
| feature | 3 | a new capability that needs new native interface |
| ignore | 26 | GTK, X11, Windows or GTK-on-macOS plumbing, refactoring, no behavior Glims needs |

Of the 26 ignored commits, ten are workarounds for GTK on macOS (shortcut redirection, Quartz drawing timing, monitor scale); a native AppKit interface does not need them.
