selected layer. Tracking updates presentation; a committed value queues one
captured-owner write. Native opacity is a layer property, so pixel/alpha locks,
groups and retained source kinds do not invent restrictions. Mask/channel
paint targets remain unchanged. Multiple or unknown layers and busy/closing
state disable the row without synchronous native reads.

the old owner's value to the new document. A pending write owns its presentation
until authoritative reconciliation. One counted completion hold protects close
through deferred idle/cache reload, including a failed native target. A passive
mouse-up monitor discards disabled tracking presentation and performs no write.
