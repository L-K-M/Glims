# Glims Help

Glims is a native macOS image editor built on the GIMP image engine. This
manual describes what Glims does today and how to drive it from the
keyboard and the mouse.

This window is searchable: type into the search field and Glims selects
the first match; press Return to step to the next one, wrapping at the
end of the manual. The section pop-up above the text shows one topic at
a time. Help > Keyboard & Mouse Reference jumps straight to the key
tables.

The image engine behind Glims is GIMP; its own user manual is on the
web. See "Engine Manual" at the end of this manual for the link.

# The Workspace

Every image opens in its own window. The image sits on a neutral
surround whose gray you choose in Preferences. Along the bottom of the
window a status strip shows messages on the left and the zoom on the
right. Its information chooser shows Dimensions, Working profile,
Precision, Canvas cache or Last tile. Canvas cache counts retained tile
pixels, including row padding; it is not the image's total memory.
Last tile is the elapsed time of the last accepted render, including
its wait for the engine. It clears when the canvas generation changes.
In a narrow window, progress and Cancel temporarily replace this readout.

These palettes hold the controls:

  Tools        the tool buttons, two columns.
  Tool Options the settings of the current tool.
  Layers       the image's layers and groups.
  Channels     the image's channels, saved selections and Quick Mask.
  Paths        the image's vector paths.
  History      the edit history and snapshots.
  Recorder     the recorded commands and their replay.
  Color        sliders and a color bar for the foreground and background.
  Swatches     saved colors for the foreground and background.
  Navigator    a small view of the image that pans and zooms the window.
  Info         readings for the pointer and the current selection.

The default layout has Tool Options under Tools at the left, and two
groups of tabs at the right: Layers, Channels, Paths, History and
Recorder, with Color, Swatches, Navigator and Info under them. An
arrangement you already have is kept; Window > Reset Palettes gives
you the default one.

In Swatches, click a swatch to make it the foreground color and
Option-click one for the background color. Click the empty space after
the last swatch to add the foreground color, Shift-click a swatch to
replace it with the foreground color and Command-click one to delete
it. The palette's menu adds the foreground color or resets the default
swatches. Your swatches are kept between launches.

In Color, choose Foreground or Background (or click its square), then
drag the sliders or type values. The palette's menu switches between
RGB, HSB and Grayscale sliders. Click the color bar to pick a color for
the chosen square, or Option-click it for the other one. Double-click a
square to type exact values in the color editor.

Palettes always follow the front image. The Window menu shows and
hides them by name, Hide Palettes (which becomes Show Palettes) hides
them all, and Reset Palettes returns them to their default layout.
With the canvas focused, Tab hides every palette and Shift-Tab hides
all but Tools; pressing either key again brings them back. While a
text field has focus, Tab stays with the field.

Window > Workspaces saves named palette layouts: choose a saved name to
apply that layout, Save Workspace… names the current arrangement (and
asks before replacing a saved one), and Delete Workspace removes saved
layouts.

# Opening, Saving and Exporting

File > New… (Command-N) creates a new image of a size you choose.
For an RGB image, Contents chooses what its one layer holds: White, the
Background Color of the Tools palette, or Transparent (a layer named
Layer 1). The new image has no history.
File > Open… (Command-O) opens image files; XCF files keep all their
layers. Open Recent lists the documents you opened lately. Close
(Command-W) closes the front image, asking first when it has unsaved
changes and naming the file Save would write.

Saving and exporting are two separate jobs:

  Save (Command-S) writes the layered XCF working file, and nothing
  else. Save As… (Shift-Command-S) saves the image under a new XCF
  name. Save a Copy… writes an XCF copy without changing the file you
  are editing.

  Export… (Shift-Command-E) writes an image as PNG, JPEG, TIFF, PSD, GIF, BMP, TGA, PCX, EPS or PDF. After exporting once, File > Export Again… (Command-E) reads
  "Export to name.png" and overwrites that file with the current
  image.

PSD offers Layers and Merged appearance for RGB and grayscale images.
Layers retains raster layers and masks, but renders effects into their pixels;
blending can change when the exported file is reopened. Merged appearance
captures the visible image as one layer, including transparency. The bundled image
engine exports 8-bit source channels at 8-bit and higher precision at 16-bit,
which cannot retain out-of-range HDR values. The supported development engine
also writes 32-bit PSD for float/u32 sources. Keep XCF for full editing and
the original precision.

For a CMYK PSD, choose Color: CMYK and explicitly select an installed printer
profile. The selected ICC profile is embedded in the output and retained by
Export Again and Batch. Install additional profiles with ColorSync. CMYK
output converts an RGB document using relative colorimetric rendering with
black-point compensation; editing remains RGB. Output uses 8-bit channels
for 8-bit documents and 16-bit otherwise. The supported development engine
currently refuses CMYK output because of a defect in its PSD writer; use the
bundled stable engine. Native CMYK editing and CMYK-preserving import are
not available.

GIF exports the visible canvas as one still image with up to 256 colors.
Pixels below 50% opacity become transparent; other pixels become opaque.
Layers, animation and higher precision remain in your XCF working file.

BMP and TGA export the visible canvas as one uncompressed 32-bit sRGB image
with eight alpha bits, including partial transparency. BMP writes V5 sRGB
information; some older readers ignore its alpha channel. TGA uses top-left
origin and embeds no ICC profile. Grayscale and indexed documents are converted
to RGB only in the export copy. High precision is reduced to eight bits per
channel. Save XCF to retain the original layers, profile and precision.

PCX exports the visible canvas as a flat sRGB PCX image. Transparency
is composited on white. PCX is limited to 65534 pixels across and 65536
down. Save XCF to retain layers, profile and precision.

EPS and PDF export the visible canvas as a single flattened page at the
image's print size, which follows from its pixels and resolution.
Transparency is composited on white. A page can be up to 200 inches a
side. Save XCF to retain layers and full editing.

Exporting never marks the document saved; only Save does. The window
title and the close prompt always name the XCF file that Save writes.

For a Lab image, choose Image > Create Linear RGB Copy… to make a
separate RGB document, then export that copy. In layered Lab images the
copy combines visible layers and keeps transparency; the original keeps
its layers and edits. An older engine may not offer this command for
layered Lab documents.

# Editing and the Clipboard

Edit > Undo (Command-Z) and Redo (Shift-Command-Z) step through the
edit history; the History palette jumps to any state directly.

Cut (Command-X) and Copy (Command-C) put the active layer's pixels on
the macOS clipboard: the selected area when a selection is active, the
whole layer otherwise. Cut removes the copied pixels from the layer
once the clipboard has them. Copy Merged (Shift-Command-C) copies
everything visible, flattened into one image.

Paste (Command-V) pastes the clipboard as a new layer in the middle of
the image. Paste in Place (Shift-Command-V) pastes it at the position
it was copied from. Paste as New Image opens the clipboard's image as
a new document of its own. Clear (Delete) erases the selected pixels
of the active layer (or the whole layer when nothing is selected); on
a layer without transparency it fills them with the background color.

Edit > Purge frees memory and cannot be undone, so each command asks
first. Undo clears the active document's undo and redo history.
Histories clears the history of every open document. All clears the
active document's history, every open document's history and the
clipboard. Clipboard clears the engine's clipboard and named buffers;
it clears the macOS clipboard only while it still holds a copy made
here, so another application's data is left alone. A purge changes no
pixels and adds no Recorder row.

Edit > Stroke Selection… opens the document's stroke sheet. It captures
the current brush (shown by its resource name), size, opacity and color
by value when it opens — editing or cancelling the sheet never changes
the global tool settings — and Stroke paints the selection's boundary on
the active layer as one undo step, leaving the selection itself
unchanged. It refuses with a reason when there is no selection, the
target is a mask, channel or layer group, the pixels are locked, the
layer still has an editable text/link/vector source (rasterize it
first), or the engine is busy.

Edit > Stroke Path draws along the active path with the foreground
color, at the width set in Tool Options. Edit > Fill Path fills the
path's area on the active layer (or its mask, or the selected channel)
with the foreground color; the fill stays inside the current selection.
Edit > To Vector Layer turns the active path into a genuine vector
layer (engine 3.2 and later). The new layer starts in the engine's
default style — a white fill and a black stroke — which the foreground
color does not affect; editing the path re-renders the layer. The Paths
palette's buttons run the same commands on the selected path.

# Tools

The Tools palette shows one cell per group. Press a tool's letter to
select its group; press the letter with Shift to cycle through the
grouped tools. The letter of each group:

  V    Move, Transform
  C    Crop
  M    Rectangle Select, Ellipse Select
  L    Lasso, Polygon Lasso
  W    Magic Wand, Select by Color
  I    Eyedropper
  T    Text
  P    Path
  B    Brush, Pencil, Airbrush
  E    Eraser
  S    Clone, Heal
  R    Smudge, Blur, Sharpen
  O    Dodge, Burn, Sponge Desaturate, Sponge Saturate
  G    Gradient, Paint Bucket
  N    Line
  H    Hand
  Z    Zoom

What the tools do:

  Move drags the active layer. Crop drags a rectangle; Return applies
  it and Escape cancels it. With Fixed Target Size on in Tool Options
  the rectangle keeps the target's proportions and Return crops and
  resamples to the set width, height and resolution as one undo step;
  an empty Resolution keeps the image's own. Transform has four modes
  in Tool Options and Layer > Transform: Scale / Rotate, Skew, Distort
  and Perspective. Skew slides an edge along its direction; Distort
  moves individual corners; Perspective moves a corner pair
  symmetrically. The first horizontal or vertical movement fixes a
  perspective drag's direction.
  Drag inside to move or outside to rotate; Shift snaps rotation to
  15-degree steps. Position, size and angle control the frame while
  preserving any warp. Return or Apply commits; Escape or Cancel drops
  the pending transform. An accepted Apply finishes before another can
  begin. Editable text, links and vector sources require the explicit
  Layer > Rasterize Layer command before a destructive transform.
  To transform a selection's shape, turn on Quick Mask (Select >
  Quick Mask), transform, and turn Quick Mask off. While Quick Mask
  or one saved selection is the target in the Channels palette,
  Transform works on that channel, boxed by the area it covers. The
  channel keeps the canvas size, so coverage moved past the canvas is
  lost. The Recorder cannot save a channel transform yet.

  Rectangle Select and Ellipse Select drag out a selection; Lasso
  draws one freehand. Polygon Lasso places a corner at each click;
  double-click, click the first corner or press Return to close it.
  Shift on the first click adds, Option subtracts; Shift on later clicks
  keeps the edge at a multiple of 45 degrees. Delete removes the last
  corner and Escape drops the polygon. Magic Wand selects the similar colors around a
  click; Select by Color takes every similar pixel in the image.
  Eyedropper sets the foreground color from the pixel you click.
  Option-click sets the background color instead.

  Line draws a straight line in the foreground color on the selected
  layer when you drag, inside the selection if there is one. Shift keeps
  it at a multiple of 45 degrees. Tool Options set its weight, opacity
  and antialiasing, and arrowheads at its start, its end or both: their
  width and length are percentages of the weight, and concavity bends
  the arrowhead's base toward its tip or away from it. Each line is one
  undo step. Masks and channels cannot be drawn on with the Line tool.

  Brush, Pencil and Airbrush paint with the foreground color. Eraser
  removes pixels on layers with transparency; on an opaque layer it
  paints with the background color selected when the stroke begins.
  Clone and Heal copy from another spot: Option-click
  to set the source, then paint. With Aligned on in Tool Options, later
  strokes keep the first stroke's distance to the source; with it off,
  every stroke restarts at the source. Setting a new source starts a new
  alignment. Set Clone's Source to Pattern to paint the current pattern,
  the one Edit > Fill uses, with no source point; the Pattern button
  chooses it. With Aligned on, the pattern stays continuous across
  strokes; with it off, each stroke starts it again. Pattern strokes
  paint only in RGB and grayscale images, and Recorder keeps them as
  failed rows. Smudge, Blur and Sharpen retouch what is already painted,
  and Dodge and Burn lighten and darken it.
  Sponge Desaturate and Sponge Saturate reduce or increase saturation under
  the brush, preserving hue and transparency. Choose either from the O tool
  group or View > Tools. Opacity sets strength; the foreground color is ignored.

  Tool Options set how the paint tools lay down paint. Mode blends the
  Brush, Pencil, Airbrush and Clone paint with the pixels under it, in
  the layer blend modes plus Behind, which paints only where the layer
  is transparent, and Color Erase. Spacing sets the distance between the
  brush's dabs as a percentage of its size; Default spacing is 10% for
  every brush. Fade, for Brush, Pencil and Airbrush, fades each
  stroke over the chosen number of dabs, to transparent or to the
  background color selected when the stroke begins, which it then keeps
  painting. A fade can be at most 32767 pixels long. These options do
  not paint in Lab, CMYK or multichannel images, and Edit > Stroke
  Selection paints in Normal at the default spacing without a fade.
  Presets keep them; Recorder keeps strokes that use them as failed
  rows.
  Sponge requires RGB pixels; grayscale, indexed images, masks and channels
  cannot be painted with it. Brush color and gradient color dynamics are ignored;
  Sponge uses the brush mask. Save a preset for either Sponge tool to retain
  its brush and strength. Recorder can capture mouse and tablet Sponge strokes on
  ordinary RGB layers, including opaque Background layers.

  Gradient drags out a gradient between the foreground and background
  colors (hold Shift to keep it at a multiple of 45 degrees); Paint
  Bucket fills similar colors around the click, or the whole selection.

  Hand drags the view; Zoom clicks to zoom in and Option-clicks to zoom
  out.

  Text: click to place text and type. Escape, Command-Return, or a
  click outside the text finishes it.

  Path: click to add anchor points, drag for curves. Return or Escape
  finishes the current subpath, and Delete removes the selected
  anchor. The Paths palette lists the paths of the image.

While painting, these keys adjust the current brush:

  [ and ]              smaller and larger brush
  Shift-[ and Shift-]  softer and harder brush
  1 to 9               paint opacity in 10% steps
  0                    paint opacity 100%

Three keys work with any tool:

  Space (hold)    temporary Hand, to pan the view
  Command (hold)  move the active layer with any tool
  Option (hold)   sample a color with any painting tool

Click either color swatch, or choose View > Tools > Foreground Color…
or Background Color…, to edit that tool color.
The modeless editor shows RGB Percent (0–100) and Float (0–1) entries
at the same time, plus a native color well. Entries retain fractions;
press Return or leave a field to apply a valid value. An invalid draft
keeps the last valid color and stays open until you correct it, choose
Revert Entries, or press Escape. Tool colors are opaque sRGB colors.
The Eyedropper and Option-paint sampling retain the native pixel's
fractions. Extended values outside the editing range are clipped with
an explicit status message; transparent pixels select black.

X swaps the foreground and background colors; D resets them to black
on white. The arrow keys move the active layer one pixel, or ten with
Shift.

# Selections

Select > All (Command-A), Deselect (Command-D) and Inverse
(Shift-Command-I) manage the selection. Feather… softens its edges;
Grow…, Shrink… and Border… reshape it; Remove Antialiasing hardens the
edges again. Smooth… takes a sample radius of 1 to 100 pixels and keeps
each pixel selected only when most of the square around it is selected,
which removes stray specks and rounds sharp corners. The canvas edge
counts as continuing the selection, so a selection that reaches the edge
stays there. Recorder saves the radius and smooths the current selection
in one undo step when you replay it. Similar adds
every pixel of the active layer whose color lies within the Magic Wand's
Threshold of the colors already selected, wherever it is in the image. It
uses the wand's Antialiasing and Sample merged options too, but always
adds to the selection without feathering. Similar is one undo step but is
not recorded. From Layer Transparency selects the visible area of the
active layer, and From Path selects along the active path.

When you start a selection drag or click with the Magic Wand, hold a
modifier to combine with the selection that exists:

  Shift           add to the selection
  Option          subtract from it
  Shift-Option    keep only the overlap

Without a modifier the mode set in Tool Options is used.

# Layers

The Layers palette lists the image's layers and groups, top layer
first. Each row shows a visibility checkbox, the layer's name and a
lock badge when locks apply. Click a row to make that layer or group
the target of painting, filters and the Layer menu. Drag rows to
reorder them or move them into a group; click into a name to edit it.
Groups open and close with the disclosure triangle.

The Layer menu: New Layer (Shift-Command-N), New Layer Group,
Duplicate Layer (Command-J), Delete Layer, Layer Properties…,
Vector Style… (the native fill and stroke of a selected vector layer,
engine 3.2 and later; solid colors only, one undo step),
Arrange > (Bring to Front Shift-Command-], Bring Forward Command-],
Send Backward Command-[, Send to Back Shift-Command-[),
Transform > (rotate and flip the layer), and Merge Down.
Image > Flatten Image merges everything into one layer.

Layer > Lock protects work in progress:

  Lock Pixels       nothing paints on the layer
  Lock Position     the layer cannot move or transform
  Lock Transparency the transparent areas stay transparent

A lock on a group applies to every layer inside it.

Layer > Mask > Add Layer Mask… creates a mask using the choices in its
sheet. Edit Mask switches painting to the mask; Show Mask displays it
on the canvas. Enable Mask toggles its effect without deleting it.
Apply Mask combines the mask with the layer's pixels, while Delete Mask
removes the mask. Mask to Selection uses the mask as a selection.

Layer > Matting cleans the colored halo along a layer's partially
transparent edge. Defringe… asks for a width in pixels (1 to 200) and
gives each partially transparent pixel the color of the nearest fully
opaque pixel within that distance, measured corner to corner; pixels
with no opaque neighbor that close keep their color. Remove Black
Matte and Remove White Matte divide out the background color left in
partially transparent pixels: black divides each color by its alpha,
white subtracts the remaining background before dividing. Transparent
and fully opaque pixels, and every alpha value, stay exactly as they
were. The commands ignore the selection and work on the whole layer,
because the halo is an edge property of the layer. Each is one undo
step. Groups, editable text, link and vector layers, locked pixels,
Lab and ink-channel documents, and layers without transparency are
refused with the reason in the menu's tool tip. Recorder saves the
operation and width and replays it on the same target.

# Filters

Filter > Blur > Gaussian Blur… opens a settings window with a live
preview on the active layer. The other entries under Filter open the
same kind of window: the settings are in a small floating window
instead of a dialog sheet, so the image stays fully visible. Move a
slider and the canvas previews the result at once; you can still pan
and zoom while the window is open.

  Apply   commits the filter as one single undo step.
  Cancel  closes the window and leaves the image untouched, as does
          closing the window.

Filter > Other > Maximum… and Minimum… take a radius of 1 to 100 whole
pixels. Each channel of every pixel becomes the largest (Maximum) or
smallest (Minimum) value in the square of that radius around it, so
light or dark areas spread. Transparency spreads the same way.

Entries that cannot run yet stay listed but disabled, and their title
says why (for example "needs a second layer as its source").

Glims also runs the engine's plug-in commands. They appear at the end
of the Image, Layer, Select and Filter menus and open their own
settings windows; one command runs at a time. Filter > Last Filter
(Command-F) runs the last native filter you applied from the Filter
menu, or plug-in command from any menu, again with the settings it
last committed, and Last Filter Settings… (Option-Command-F) opens
that filter's own settings window at those settings. A filter that cannot
run again without its settings window, such as one that reads a
layer, mask or channel you choose as its source, is still named but
Last Filter stays disabled. Recently Used lists native filters and
plug-in commands together, most recent first. Commands under Image >
Adjust are adjustments, not filters, so applying one does not change
Last Filter.

Image > Adjust carries one-click commands that act on the active layer,
its mask while you edit it, or the selected channel. Auto Levels
(Shift-Command-L) stretches each RGB channel's range, Desaturate
(Shift-Command-U) turns the layer into HSL lightness grays, and
Equalize flattens its histogram; all three respect the selection and are
one undo step. Desaturate needs an RGB layer. Layer > Add Transparency
and Remove Transparency change the layer's format; Remove Transparency
composites transparent pixels on the tool background color. Groups,
editable text, link and vector layers, locked pixels, and Lab or
ink-channel documents are refused with the reason in the menu's tool
tip. Recorder saves the adjustment and its background color and replays
it on the same target.

# History and Snapshots

The History palette lists every edit state the image keeps, with the
state you are viewing marked. Click any row to return the image to
that state, then edit from there; Edit > Undo and Redo step one state
at a time.

Image > New Snapshot (also the Snapshot button in the History palette)
opens an independent copy of the current image in a new window, named
after the original with " snapshot" added. It is an ordinary document:
edit it, export it or close it without affecting the original.

Image > Duplicate... does the same under a name you choose ("As", by
default the original's name with " copy" added). Merged Layers Only
gives the copy a single layer with what the visible layers show,
transparency included; hidden layers are left out. It is offered for
layered RGB, grayscale and indexed images and is dimmed when the image
has one layer. The copy starts with an empty history.

Image > Rotate > Arbitrary... turns the whole image by any angle up to
359.99 degrees, clockwise or counter-clockwise. The canvas grows to hold
the turned image. A background layer fills its new corners with the
background color; other layers leave them transparent. It is offered
for layered RGB, grayscale and indexed images and is one undo step.
The Recorder saves the angle, direction and background color.

Image > Image Size… changes the pixel dimensions, the print size and the
resolution together. Print width and height accept inches, centimeters,
millimeters, points or picas; the resolution accepts pixels per inch or
per centimeter. With Resample image on, the print size and resolution
drive the pixel dimensions and the image is resampled with the chosen
method. With it off, the pixels stay fixed and the print size and
resolution move inversely. Constrain proportions keeps width and height
in step. The whole change is one undo step. File > New… takes a
resolution with its own unit and a width and height unit (pixels,
inches, centimeters or millimeters), defaulting to 72 ppi. Image >
Image Information… shows the resolution and the print size. Changing a
unit converts the numbers. Image Size needs an ordinary layered image:
CMYK, Lab and Multichannel documents keep the resolution they were
created with. An older engine keeps the pixel-only Image Size sheet.

Layer > Align moves the selected layers so the edges or centers of
their visible pixels line up: Top Edges, Vertical Centers, Bottom
Edges, Left Edges, Horizontal Centers or Right Edges. With a selection
the layers align to the selection's edges, so one layer is enough;
without one they align to the active layer, which stays put. Deselect
any group containing the active layer before aligning to it. Layer >
Distribute spaces three or more selected layers' edges or centers
evenly between the outermost two. Position-locked layers refuse. Each
command is one undo step.

# Recorder

The Recorder palette records the edits Glims can replay and runs them
again later. Window > Recorder shows the palette; Edit > Recorder and
the palette's own buttons expose the same commands.

  Record             start a fresh recording for the front image,
                     replacing the commands it recorded before.
  Stop               stop accepting new commands; commands already
                     accepted still finish and keep their order.
  Replay             run the recorded commands in their recorded order.
  Cancel Replay      stop scheduling further commands; accepted work
                     may still finish.
  Clear              remove the recorded commands without touching the
                     image.
  Name Recording…    change the recording's title.
  Save Recording…    write the recording to a .glimsrecording file.
  Load Recording…    read a .glimsrecording file into this image.

While a recording runs, the palette lists each command in acceptance
order, marked Recorded, Failed or Cancelled, and shows how many
accepted commands are still pending. Stop leaves that count visible
until the accepted work settles, and the palette waits for it before
offering Replay or a new Record.

Stop recording and wait for pending work before naming, saving or
loading a recording.

Recorded commands cover: rectangle, ellipse and polygon selections
with their options; Select by Color with its point and options; the
selection commands (All, None, Invert, Feather, Grow, Shrink, Border,
Sharpen, Select Alpha) with their radius; Channel to Selection from
the Channels palette, with its Replace/Add/Subtract/Intersect
operation and the explicit source channel it was invoked on; image
rotation and flipping; image scaling with its resampling method;
canvas resizing with offset and fill color; image cropping; layer name,
visibility, opacity and blend mode changes; affine and perspective
layer transforms with their resampling method; newly applied Levels, Curves, Color Balance,
Hue/Saturation and Brightness/Contrast adjustments with their complete settings;
newly applied Gaussian Blur and Unsharp Mask filters with their complete
settings; a Move Layer offset from a Move-tool drag or an arrow-key nudge;
Duplicate Layer and Delete Layer with one selected layer; Merge Visible;
Add Layer Mask; Select Similar; and complete Pencil, Eraser, Paintbrush and Sponge strokes on
ordinary pixel layers. A stroke keeps the settings used when it was
drawn, including accepted tablet rotation and tangential pressure. Replay
checks that the required brush and its supported paint dynamics still match
the recording; unsupported brushes or dynamics
cannot be recorded. Eraser recordings retain the selected background color,
including when the target layer is opaque. Sponge replay also checks the direction
and whether the target layer has alpha. Older engines may be unable to use the
selected Eraser background or record opaque Eraser, Sponge or tablet strokes.
To Selection from the Quick Mask channel still
applies the live edit but records a failed row. Other filters, and changes
to an existing filter effect, also apply live but record a failed row, so
Replay refuses the incomplete recording.

In CMYK and Multichannel images, Recorder captures complete Brush and Pencil
gestures on the selected ink channel. Save and Load retain the accepted color,
opacity, brush settings and mouse or tablet samples. Choose a compatible ink
channel when loading into another image. Replay checks the recorded brush
before painting. Escape cancels a captured ink gesture without an Undo step.
Airbrush painting remains available but cannot yet be recorded. Older image
engines retain live painting and report unsupported recording explicitly.

In Lab images, Recorder also captures physical Fill, Levels, Curves and complete Brush
strokes. Select the L*, a* or b* channel before recording. Levels endpoints use
L* 0–100 or a*/b* −128–127; Apply commits the preview and Cancel keeps the
original. A Lab Brush recording
keeps its physical value and tablet samples. Loading it in another Lab image
requires choosing the same kind of axis and precision; Replay requires that
axis to remain selected. Changed brushes refuse replay before painting.
An engine or brush without capture support still paints but adds a failed
recording row. Lab Rectangle, Ellipse, Lasso, Select All, Select None and
Invert Selection are also recordable. These root-mask commands require a Lab
destination but do not depend on its selected axis.

Not every edit is recorded: other layer changes, other effects and file
operations stay outside the capture. The reparenting Move Layer command is
named Reorder Layer in its failed row. Duplicate Layer and Delete Layer
with two or more selected layers also keep a failed row. While a recording
runs, such an edit
still adds one explicit unsupported row that names it, so the recording
never looks complete while leaving an edit out, and Replay refuses it. An
edit refused before it starts, a preview and its Cancel, a cancelled file
import, a target pick, a view change, a save, an export and a read add no
row, and Replay adds no row of its own. A plug-in keeps its row even when
you cancel it, because it may already have changed the image. A live
recording belongs to one open image; to reuse a saved recording in another
image, load it there.

Save Recording… writes a .glimsrecording file with the commands,
their settings, outcomes and original target descriptions. The file
holds no image pixels and is separate from the image's own files; Save
still writes only the XCF working file. Load Recording… reads the
file in the window that invoked it; when commands name specific
layers, channels or masks, a binding sheet asks you to choose each
live target explicitly, because a matching name is only a description
and never picks a target by itself. Loading installs the command list;
Replay is what edits the image.

Before replacing an unsaved recording or closing, quitting or
reverting its image, Glims offers Save, Discard Changes or Cancel for
the recording separately from the image's own changes.

Replay runs against the image's current state. Each replayed command
keeps its normal Undo behavior; the recording is not one single undo
step, and a command that changes nothing need not add an Undo step. If
a command fails, replay stops at that command and reports its number
and reason, and the changes already made stay in place. Cancel Replay
works the same way: later commands are not scheduled, a command
already running may still finish, and nothing is rolled back. A
recording with any Failed or Cancelled row cannot be replayed, so a
partial success never passes for a complete macro.

# Batch

File > Batch… runs a saved .glimsrecording on several images. Choose the
recording, input files or folders, an output folder, and XCF or PNG/JPEG/TIFF/PSD/GIF/BMP/TGA.
Folders contribute visible files directly inside them, without subfolders
or links. Files the editor cannot open appear as individual failures.

The default target policy accepts recordings that need no particular
layer or channel. For target-bound recordings, explicitly choose matching
by name and kind, or by name, kind and the full group path. A missing or
ambiguous target refuses that image. Batch never guesses from layer order
or dimensions, and required layer masks must exist.

Each image is opened privately. Only a complete successful replay and save
publishes an output, with “edited” and a number as needed in its name.
Original inputs and existing output files are never replaced. The results
list gives each saved path or failure; later inputs continue after a failure.

Cancel stops later inputs and prevents publishing the current image once
its accepted work drains. Already published results remain. Batch waits
between commands when another document uses the engine. Closing the Batch
window requests cancellation; quitting waits for its cleanup to finish.
Only commands supported by the Recorder can be used in Batch.

# Zoom and Pixels

View > Zoom In (Command-Plus), Zoom Out (Command-Minus), Fit Image
(Command-0) and Actual Pixels (Command-1) change the view. Fit Image
fits the window without enlarging a small image. The zoom field in the
status strip shows the percentage; type a new value or step it with
the - and + buttons beside it.

Zoom percentages count physical pixels. At 100% (Actual Pixels) one
image pixel is exactly one pixel of your screen, whatever display you
are on: on a Retina display the image looks smaller in points than on
a standard display, but every image pixel is shown crisply, one to
one. Use Fit Image for an overview and Actual Pixels when the exact
pixels matter.

The rulers label in the unit chosen in View > Ruler Units or from a
ruler's own menu (right-click or Control-click). Inches, centimeters,
millimeters, points and picas follow the image's resolution, across on
the top ruler and down on the side one; Percent is of the image's
width or height. In a rotated view the rulers measure the rotated
image's bounds. Drag out of a ruler to add a guide. View > Clear
Guides removes all guides as one undo step; Lock Guides turns it off.

Image > Histogram… shows the tonal distribution of the active layer,
mask or channel, limited to the selection when there is one. Choose a
channel from the popup; Mean, Std Dev, Median and Pixels describe it,
and pointing at the histogram shows that level's Count and the
Percentile of pixels at or below it. Levels run from 0 to 255. Like
GIMP's Histogram, it describes one layer rather than the merged image,
and it changes nothing.

# Preferences

Glims > Preferences… (Command-Comma) controls appearance, opening zoom
and recovery copies:

  Appearance      Classic Light, Neutral Gray or Dark for Glims'
                  windows and palettes.
  Canvas Surround the gray around the image: Light Gray, Medium Gray
                  or Dark Gray. A neutral surround keeps your tone
                  judgement honest.
  Open Images At  whether newly opened images start at Fit Image or
                  at Actual Pixels.
  Recovery Copies keep private periodic copies of open images.
  Copy Every      choose the interval between recovery copies.

Appearance and canvas surround apply immediately. Open Images At
applies to newly opened images. Recovery settings update the running
scheduler; a copy already in progress can still finish.

# Engine Manual

Glims is built on the GIMP image engine, and the GIMP user manual
documents how that engine treats images: layers, selections, painting
tools, filters, color modes and file formats. The concepts carry over
to the images you edit in Glims.

Help > Engine Manual opens the GIMP documentation website in your web
browser:

  https://docs.gimp.org/

This is a link to a website outside Glims; nothing is downloaded
until you choose the menu item. The windows and menus shown in that
manual are GIMP's own; Glims drives the same engine through its own
Mac interface, which the sections of this manual describe.
